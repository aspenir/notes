In science, the order of importance of statistical values are:
1. Resolution
2. Precision
3. Accuracy

_Accurate_ data successfully matches the correct result
_Precise_ data has very little variation
_Repeatable_ data means the original experimenter can get the same results/conclusion when doing the same method again
_Reproducible_ data means a different experimenter following the same method can find similar results.
