There are 7 SI (Systéme International) base units:

| Quantity               | $\dim Q$ | Unit name | Unit symbol |
| ---------------------- | -------- | --------- | ----------- |
| Mass                   | $M$      | kilogram  | kg          |
| Time                   | $T$      | second    | s           |
| Length                 | $L$      | metre     | m           |
| Current                | $I$      | ampere    | A           |
| Temperature            | $\Theta$ | kelvin    | K           |
| Amount                 | $N$      | mole      | mol         |
| Luminous <br>intensity | $J$      | candela   | cd          |

All other units can be derived from these 7:









$$
\begin{aligned}
\dim F &=\dim (ma) \\
&=[\mathsf{M}][\mathsf{L}\mathsf{T}^{-2}] \\
&=[\mathsf{M}\mathsf{L}\mathsf{T}^{-2}] \\
\implies1\text{N}&=1\text{kg}\text{ m s}^{-2}
\end{aligned}
$$

















$$
\begin{aligned}
\dim R &= \dim \left( \frac{V}{I} \right) \\
&= \dim \left( \frac{P}{I} \right)[\mathsf{I}^{-1}] \\
&=\dim (FL)[\mathsf{I}^{-2}\mathsf{T}^{-1}] \\
&=[\mathsf{M}\mathsf{L}^2\mathsf{T}^{-3}\mathsf{I}^{-2}] \\
\implies1\Omega&=1\text{kg m}^2 \text{s}^{-3}\text{A}^{-2}
\end{aligned}
$$









### SI prefixes
Sometimes we use measurements that are so large or small that its unwieldy to use the SI unit to represent them. The system provides a set of prefixes in multiples of $10^3$ to make this easier

| Prefix | Symbol      | Multiplier |
| ------ | ----------- | ---------- |
| pico-  | $\text{p}$  | $10^{-12}$ |
| nano-  | $\text{n}$  | $10^{-9}$  |
| micro- | $\text{μ}$  | $10^{-6}$  |
| milli- | $\text{m}$  | $10^{-3}$  |
| centi- | $\text{c}$  | $10^{-2}$  |
| deci-  | $\text{d}$  | $10^{-1}$  |
|        |             | $10^0$     |
| deca-  | $\text{da}$ | $10^1$     |
| hecto- | $\text{h}$  | $10^2$     |
| kilo-  | $\text{k}$  | $10^3$     |
| mega-  | $\text{M}$  | $10^6$     |
| giga-  | $\text{G}$  | $10^9$     |
| tera-  | $\text{T}$  | $10^{12}$  |
| peta-  | $\text{P}$  | $10^{15}$  |
